#+title: yoshi

* retired
this project is retired and archived. it has been superseded by
rpass, a command-line password manager in rust:

https://gitbay.org/krz/rust-pass

vaults created by yoshi are not readable by rpass; the two use
different storage and encryption schemes. export anything you need
before switching.

* what it was
command-line password manager in python + sqlite3. managed accounts
and generated random passwords (ascii, min 8 chars) or xkcd-style
passphrases (min 3 words).

the source remains here, read-only, for reference.
